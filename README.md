# Cambio de precio

Formulario público para que los dueños de grupos reporten aumentos de precio de las plataformas.

- Sitio estático (GitHub Pages) en https://cambiodeprecio.somoslank.com
- Guarda cada reporte en Supabase (tabla solicitudes_cambio_precio) mediante las funciones plataformas_para_formulario y crear_solicitud_cambio_precio. Las capturas van al bucket privado capturas-cambio-precio.
- Solo usa la llave pública (anon) de Supabase. No agregar claves secretas a este repo.
